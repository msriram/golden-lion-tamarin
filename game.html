Tamarin Trails: Reconnect the Rainforest

Build a route that can grow, work, and last.

Connect three forest groves with tree bridges, then grow new cover in the surrounding meadows. Work with landowners, raise community support, and observe the tamarins’ route.

Bridge-first planting is a game progression rule; real forest restoration can begin without bridges. This is a teaching landscape. Game costs use fictional Forest Credits (FC). No real wildlife locations, donation data, or child information are collected.

    How to win

    Habitat first. Evidence next.

    1. Secure consent

      Use the agreement tool on the farm-edge planting area.

    2. Restore the route

      Build both tree bridges across the gaps. After eight simulated weeks, plant the three named restoration areas.

    3. Let time pass

      Young restoration cannot become instant habitat. Use 4× speed, but the model still advances week by week.

    4. Observe use

      A finished route is not counted as successful until the simulated family actually uses it.

    Why no instant trees?

    Real corridors need site preparation, mixed native plantings, maintenance, and years of growth. This scenario compresses that work to 104 weeks so it can be played in class.

    Why ground wildlife barely changes?

    A canopy rope crossing is designed for arboreal animals. Ground mammals need different routes such as suitable overpasses or underpasses.
